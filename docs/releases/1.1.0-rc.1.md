# TMC desktop 1.1.0-rc.1 - local Windows candidate

This candidate prepares the first stable 1.1.0 release from integrated main
6c651fc6604b68dac1cdfc090aaa0cae72487da4. It is not a published stable release.
No tag, GitHub release, asset upload, website deployment or user installation is
part of candidate preparation. Internal package/profile identity stays unchanged.

## Included behavior

- Guided chat login, saved accounts and persisted active selection.
- Channel navigation, favorites, rich history/live chat, emotes and account picker.
- Replies, links, autocomplete, mentions, search and appearance preferences.
- Per-account PCG/Twitch web sessions shared with opt-in video playback.
- Embedded video at the larger startup layout, detach/attach and Play/Stop controls.
- Icon-only badges and Twitch author colors in history and live messages.
- Bundled welcome/help, version display, desktop release metadata and installer shortcuts.

## Qualification blocker correction

The first local RC Electron scenario stopped after a Windows EPERM replacing the
account-channel preferences file. Deterministic regressions confirmed overlapping
channel transactions could lose preferences or interfere through the shared
atomic temporary file, and broad read-error fallback could overwrite existing
state. The exact OS cause of that first EPERM is not independently established.

This candidate serializes the existing owner's complete transactions/reads,
preserves read/schema failures, and carries initiating identity through trusted
IPC and renderer awaits. It adds no new store, retry loop, token access or
permission downgrade. Permanent storage errors remain visible. Separate source
and hosted evidence must qualify this correction before packaging proceeds.

Use Node 24.22.3 / npm 11.19.1. Qualify the exact source commit with unit tests,

inside the installer package. Keep SHA-256 hashes, source commit and scoped evidence
in the local candidate manifest beside the installer. Record exact-head hosted CI
separately; an older passing main run does not qualify this candidate.

The executable directory and installer remain under the paths documented in
[local Windows packaging](../windows-local-package.md). Generated artifacts,
profiles, binaries and evidence stay out of Git. Actual qualification results and
missing evidence are recorded in the candidate PR and local manifest.

## Limits and publication boundary

The user explicitly chose to skip the remaining formal manual checklist on
2026-11-26, reporting successful ordinary application use. Individual unperformed
offline/recovery, account-removal and clean-machine checks are not marked passed.
Prior scoped real-account observations remain distinct from automated evidence.

The Windows candidate is unsigned and retains the current default Electron icon.
The 2026-11-26 audit reports four moderate development-tooling records and no
low/high/critical records in the locked graph. They remain on the documented
WDIO/archiver/readdir-glob/minimatch chain. Registry metadata still lists archiver
8.0.0 with readdir-glob ^3.0.0, while readdir-glob 4.0.0 admits minimatch ^11.0.1;
forcing that major outside its owner's range is not a supported remediation.
No dependency, override or audit suppression is introduced. Zero production npm
records would not be an Electron runtime security audit.
The earlier Welcome timeout in dev.30 was not reproduced and has no confirmed
cause; the packaged smoke retains local dialog diagnostics on future failures.

An RC intentionally makes no automatic GitHub update check, as documented in
[welcome and updates](../welcome-and-updates.md). Synthetic tests exercise stable
update scheduling and metadata through local substitutes; RC qualification does
not prove a live public stable download. Promoting to final 1.1.0 requires a new
versioned build and final qualification, including stable-only startup behavior.
No external account identity or ad-free playback is inferred from cookie presence.
Publishing, signing policy, final website/download changes and a final version/tag
remain separate decisions. No release publication is authorized by this preparation.
