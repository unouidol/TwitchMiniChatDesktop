## What's new in 1.1.1?

A patch release for problems reported after 1.1.0.

**Fixed**
- **Crash when closing a separate window.** Closing the separate PCG window (or the PCG Twitch sign-in window) could stop the app with "A JavaScript error occurred in the main process — Object has been destroyed". This no longer happens.
- **"Remove account…" looked like it was loading forever.** Unavailable buttons now show a "not allowed" cursor instead of a busy cursor.

**New**
- **Sign out of PCG and video.** While PCG is signed in to Twitch, open the PCG **•••** menu and choose **Sign out of PCG and video…**. This signs that account out of the Twitch web session used by PCG and the video player. Chat stays signed in; use **Sign in for PCG and video** to sign in again.
- **Removing an account now also signs it out of PCG and video** on this device. In 1.1.0, an account that was removed and added again came back already signed in to PCG.

## What to download

Download **`TMC-desktop-Setup.exe`** for Windows 10/11 **x64**. Installing it upgrades an existing 1.1.0 installation; saved accounts and settings are kept.

The `.nupkg` and `RELEASES` files are Squirrel packaging metadata; use the Setup executable to install the app.

### Important: this Windows package is unsigned

This release has **no code-signing certificate**. Windows may show an unrecognized-app warning or block execution, depending on your security settings. The publisher's identity is not verified by a digital signature. Do not disable Windows security protections to install TMC.

Download only from this repository's release assets or the links on the [TMC website](https://tmc.ircminichat.party/#downloads). SHA-256 checksums help verify that downloaded bytes match these assets; they do not replace a publisher signature.

## How to upgrade

1. Close TMC desktop and any separate video or PCG window.
2. Download the Setup executable, check its checksum, and run it if your Windows security policy permits it.
3. Open **TMC desktop (installata)**; the window should show **1.1.1**.
