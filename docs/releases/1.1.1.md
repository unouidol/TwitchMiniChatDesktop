# TMC desktop 1.1.1 - preparation record

Patch release for problems users reported in 1.1.0 on 2026-11-27.

## Changes

- **Crash when closing the detached PCG window** (PR #20). While a BrowserWindow
  emits `closed`, Electron 43 still lists it in `getAllWindows()` and
  `isDestroyed()` is false, but its WebContents is already destroyed; the PCG
  status broadcast from that handler threw "Object has been destroyed" in the
  main process. All window broadcasts now skip destroyed WebContents.
- **Busy cursor on unavailable buttons** (PR #20). "Remove account..." looked like
  an endless account lookup; disabled buttons now show `not-allowed`.
- **Sign out of PCG and video** (PR #21, completion signal and E2E race fixed in
  PR #22). PCG options offer "Sign out of PCG and video..." while a Twitch web
  session is present. "Remove account..." now also clears that account's web
  storage; in 1.1.0 a removed and re-added account came back signed in to PCG.
- **Hosted release build** (this PR). `.github/workflows/release.yml` builds the
  release from one exact `main` commit on a Windows runner and stages a draft.

## Qualification plan

The release workflow, run on the merge commit of this PR, must:
use Node 24.22.3 / npm 11.19.1; verify package version and that no `v1.1.1`
tag or release exists; build from a clean tree and verify the build changes no
tracked file; repeat behavior tests, types and lint; make the Windows package;
run the protected-package smoke and Squirrel lifecycle tests; publish assets
with SHA-256 checksums only to a draft release.

Publication (which creates tag `v1.1.1` at the built commit) is a separate,
authorized step. Results recorded below belong to that exact commit.
