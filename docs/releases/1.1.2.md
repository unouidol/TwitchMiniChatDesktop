# TMC desktop 1.1.2 - preparation record

Patch release for memory use reported by users ("more memory than five browsers
with one account each") and for the health-check security follow-ups.

## Changes

- **PCG panel per account** (PR #30). Up to 1.1.1 every account switch created a
  new PCG view and the previous one stayed alive after a forced GC: the Windows
  E2E memory scenario counted 14 live PCG pages before the scenario and 24 after
  10 switches (renderers 1698 -> 2665 MB on inert fixture pages). Panels are now
  kept one per account and reused without reloading; removal and PCG sign-out
  close them. After the fix: 2 pages (same ids) after 10 switches, renderers
  541 MB, total 795 MB in the same scenario.
- **Chat row cap** (PR #29). 1000 rendered rows per open channel; measured growth
  without it ~14 MB per 1000 synthetic rows (1474 MB at 100k).
- **External links and redirects** (PR #28). Links from PCG/Twitch pages need
  confirmation; foreign main-frame redirects are blocked; every IPC handler
  checks its sender (20 had no check).

## Qualification plan

As for 1.1.1: the Release build workflow on the merge commit of this PR builds
from a clean tree, repeats tests, types and lint, makes the Windows package, runs
the protected-package and Squirrel lifecycle smoke tests and stages a draft with
checksums. The checksums and build run are then added to
`docs/releases/1.1.2-notes.md`, and Publish release runs behind the maintainer's
approval.

## Remaining limits

Fixture pages are lighter than real Twitch/PCG pages, so the megabytes above
understate real use; no real-account comparison with five browsers was made. The
external-link prompt and redirect blocking are verified by tests, not against
real PCG links. Unchanged from 1.1.1: unsigned package, default icon, no
clean-machine/offline acceptance.
