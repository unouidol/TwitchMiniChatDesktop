## What's new in 1.1.2?

A patch release focused on memory use and on safer handling of links and web pages.

**Lower memory use**
- **Switching accounts no longer piles up PCG pages.** Until 1.1.1, every account switch loaded a new PCG panel and kept the previous one in memory, so memory use kept growing the more you switched. Each account now keeps one PCG panel, and switching back shows it again without reloading. In automated tests on Windows, ten account switches went from 24 PCG pages left in memory to 2 (one per account).
- **Chat keeps the most recent 1,000 messages per channel.** Older messages were never removed while a channel stayed open, so a busy chat kept growing for hours. Older messages now leave the chat as new ones arrive. If you scroll up to read, the message you are reading stays in place. Search only finds the messages still shown.

**Safer links and pages**
- **Links from PCG and Twitch pages ask before opening your browser.** A link to a site outside Twitch opened from the PCG panel, the separate PCG window or the Twitch sign-in window now shows "Open *site* in your browser?" first. Links you click in chat open as before.
- **PCG and Twitch pages can no longer be redirected to other websites inside TMC.** Such a redirect now asks to open the site in your browser instead.
- **Internal hardening.** Every internal request inside the app now checks that it comes from the TMC window itself.

## What to download

Download **`TMC-desktop-Setup.exe`** for Windows 10/11 **x64**. Installing it upgrades an existing 1.1.x installation; saved accounts and settings are kept.

The `.nupkg` and `RELEASES` files are Squirrel packaging metadata; use the Setup executable to install the app.

### Important: this Windows package is unsigned

This release has **no code-signing certificate**. Windows may show an unrecognized-app warning or block execution, depending on your security settings. The publisher's identity is not verified by a digital signature. Do not disable Windows security protections to install TMC.

Download only from this repository's release assets or the links on the [TMC website](https://tmc.ircminichat.party/#downloads). SHA-256 checksums help verify that downloaded bytes match these assets; they do not replace a publisher signature.

## How to upgrade

1. Close TMC desktop and any separate video or PCG window.
2. Download the Setup executable, check its checksum, and run it if your Windows security policy permits it.
3. Open **TMC desktop (installata)**; the window should show **1.1.2**.
