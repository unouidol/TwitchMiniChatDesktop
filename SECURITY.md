# Security policy

## Supported versions

Only the [latest release](https://github.com/unouidol/TwitchMiniChatDesktop/releases/latest)
receives security fixes. Please update before reporting.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Email **unouidol.interactive@gmail.com** with:

- what an attacker could do, and under which conditions;
- steps to reproduce, and the TMC desktop version (shown in the window title);
- whether the problem is already public.

Never include access tokens, cookies, passwords or other secrets, yours or
anyone else's, in a report.

You will get an answer as soon as possible; TMC is maintained by one person, so
please allow a few days. Fixes ship in a new release with a note in its release
notes.

## Scope

In scope: the TMC desktop app in this repository and its release assets.
Out of scope: Twitch, the Pokémon Community Game extension and other third-party
services, which have their own security contacts.
